# 週一去哪

兩個人週日夜、週一休假的約會行程抽籤網頁。

- `index.html`：網頁本體
- `data/places.json`：地點資料（每月自動更新）
- `data/movies.json`：電影清單（每週自動更新）

個人資料（標記、帳本、約會紀錄）只存在手機瀏覽器裡，不會上傳。


## 全台旅行
- 出發／回家可選任何日期時間，跨夜會自動分成每天的行程並估住宿。
- 目的地：高雄附近、台南、屏東、墾丁、嘉義、阿里山、彰化鹿港、台中、日月潭清境、新竹、台北新北、宜蘭、花蓮、台東。
- 交通費：台鐵 2025/6/23 新票價、高鐵現行票價（轉乘段為估算）；油錢 = 公里 ÷ 油耗 × 油價（data/meta.json 的 fuel）；開車另估國道 ETC。
