設定每月自動找新店

每月 1 號會用 Google 地圖找評價好的新店。要先申請一把 Google 地圖金鑰（只要做一次）：

  1. 用電腦打開 Google Maps Platform，用 Google 帳號登入，照指示建立專案、綁信用卡（新帳號有免費額度，每月找一次新店約查 22 次，遠低於免費上限）。
  2. 在「API 和服務」→「程式庫」搜尋 Places API (New)，按「啟用」。
  3. 到「憑證」→「建立憑證」→「API 金鑰」，複製那串金鑰。建議按「編輯 API 金鑰」→「API 限制」只勾 Places API (New)。
  4. 保險起見到「帳單」→「預算與快訊」設一個 100 元的預算提醒。
  5. 打開 GitHub 金鑰設定頁，Name 填 GOOGLE_MAPS_KEY，Secret 貼上金鑰，按 Add secret。
  6. 想馬上試：打開 每月找新店 →「Run workflow」。約 1 分鐘後回來重新整理，上面的狀態就會更新。
